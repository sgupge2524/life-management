# 学生時代に最も力を入れて取り組んだことは何ですか？

私が学生時代に最も力を入れて取り組んだことは、大学3年生の後期の授業で行ったチーム開発です。JavaとSpringBootを用いて図書管理システムを開発しました。

私は副リーダーとして開発の進行管理を担当しました。当初、メンバー間で作業内容が曖昧だったため、Gitのコンフリクトや作業の遅れが発生してしまいました。

そこで私は、開発を円滑に進めるために機能ごとに役割を明確に分担し、締め切りを明確に決めました。また、作業目標を設定し、メンバー全員が締め切りを意識して開発を進められるようにしました。

その結果、大きなコンフリクトも発生せず、締め切りまでに図書管理システムを完成させることができました。この経験から、チーム開発では技術力だけでなく、役割整理や進行管理によってチーム全体の生産性を高めることが重要であると学びました。

# 就活軸は何ですか？

私の就活軸は、システムを通して多くの人の課題を解決し、価値を提供できるエンジニアになれるかという点です。そのために3つの軸を持っています。

一つ目は、幅広い分野に携われることです。様々な業界やシステムに関わることで、より多くのお客様の課題解決に貢献できると考えています。

二つ目は、上流工程から下流工程まで一貫して携われることです。要件定義や設計の段階から開発まで関わることで、お客様の課題をより深く理解し、それをシステムとして形にできると考えています。

三つ目は、本質的な課題解決に関われることです。お客様の要望をそのまま実装するのではなく、背景にある課題を整理し、最適な形でシステム化することで価値を提供できるエンジニアになりたいと考えています。

以上の理由から、幅広い分野に携われること、上流から下流まで関われること、本質的な課題解決ができることを就活の軸としています。

# 御社を志望した理由は何ですか？

御社を志望した理由は、私の就活軸と大きく一致していると感じたためです。私は、システムを通して多くの人の課題を解決し、価値を提供できるエンジニアになりたいと考えています。そのため、幅広い分野に携われること、上流から下流まで一貫して開発に関われること、本質的な課題解決ができることの3つを就活軸としています。

その中で御社は、幅広い分野のお客様と取引をされており、様々な業界のシステム開発に携われる点に魅力を感じました。多様な分野の課題解決に関わることで、より多くの方に価値を提供できるエンジニアになれると考えています。

また、御社では上流工程から下流工程まで一貫して開発に携わることができ、お客様と近い距離でシステム開発を行える点にも魅力を感じました。お客様の課題を理解し、それをシステムとして形にする経験を積める環境で成長したいと考えています。

さらに御社では、チャレンジポスト制度を導入されており、自身の挑戦したい分野やキャリアについて経営層に直接意思を伝えられる点に魅力を感じています。
主体的にキャリアを切り拓きながら専門性を高めていくことで、自身のスキルの幅を広げ、より多様な課題に対応できるエンジニアへ成長できると考えています。
その結果、より多くのお客様の課題に対して最適な価値提供ができると考えています。

↓

私はこの制度を活用し、上流工程から下流工程まで幅広く経験を積むことで、開発全体を理解したいと考えています。
その上で将来的には、プロジェクトリーダーとして全体を俯瞰しながらチームをまとめられる存在になりたいと考えています。
各工程の動きを把握することで、より効率的かつ適切な判断ができるエンジニアへ成長したいと考えています。

このような環境で経験を積みながら、お客様の課題を本質的に解決し、多くの方に価値を提供できるエンジニアへ成長したいと考え、御社を志望いたしました。

# あなたの強みは何ですか？


私の強みは、入念に計画を立て最後までやりきる責任感です。

高校3年生の時に文化祭実行委員として会場設営と用具管理のチーフを務めました。当初は各教室で必要な備品や数が把握できておらず、

このままでは不足や紛失が起こる可能性がありました。そこで私はまず各教室の備品情報を整理し、必要数を確認しました。さらに当日の備品移動のシミュレーションやダブルチェックを行う体制を作りました。

その結果、備品の紛失や不足なく文化祭を成功させることができました。この経験から、計画を立てて責任を持ってやり遂げる力が私の強みだと考えています。

↑ なぜチーフになりたいと思ったのか？

チーフを志望した理由は、より多くの人に直接的に価値を提供し、喜んでもらいたいと考えたためです。

中学校や高校で実行委員を務める中で、人のために行動し喜んでもらえることにやりがいを感じてきました。

その中でチーフは全体に影響を与える立場であり、自分の工夫や行動によってより多くの人に価値を届けられると考え、志望しました。

↑ なぜ経験したいと感じたのか？

周りをまとめる人がどういう気持ちなのか知りたいと感じたから。

チャレンジしたいと思ったから。

# あなたの弱みは何ですか？

私の弱みは、一つのことに集中すると視野が狭くなってしまう点です。課題に取り組んでいると、解決することに意識が向きすぎてしまい、周囲の状況への意識が薄くなることがあります。

そのため現在は、作業に入る前にタスクを整理し、全体の状況を把握しておくことを心がけています。また、作業に集中しすぎないよう、適度に進捗を確認することで周囲とのコミュニケーションを意識するようにしています。

一方で、この性格は課題を解決するまで粘り強く考え続けられる集中力という強みにもつながっていると考えています。今後も周囲との連携を意識しながら、この集中力を課題解決に活かしていきたいと考えています。

# なぜエンジニアになりたいのですか？

私がエンジニアを目指した理由は、システムによって業務や作業が効率化されることに大きな魅力を感じたからです。

大学生活の中で、ソフトウェアやアプリケーションを活用することで作業が効率化され、今まで時間がかかっていたことを短時間で行えるようになる経験をしました。その結果、空いた時間を他のことに使うことができ、ITの力によって人の生活や作業がより良くなることを実感しました。

この経験から、自分もシステムを作る側として人の作業を効率化し、より多くの人が時間を有効に使える環境を作りたいと考えるようになりました。そのため、IT技術を用いて課題を解決できるエンジニアを目指しています。

---

# どんなエンジニアになりたいのですか？

私は、人の生活をより便利にできるエンジニアになりたいと考えています。

大学生活の中で業務効率化システムや学習支援システムを活用することで、作業の負担が減り、時間を有効に使えるようになりました。

この経験から、システムによって人の生活を豊かにできることを実感しました。私もそのような価値を提供できるエンジニアになりたいと考えています。

# なぜ福岡で勤務したいのか？

私は、地元福岡が住みやすく好きという理由があって、福岡に勤務したいというのはもちろんなのですが、

その地域の徳署について知っていることが、エンジニアとしてお客様を喜ばせるための強みになると考えていることも理由です。

大きくはないですが、地域によって変化は多くあります。そんな小さな変化にも対応できるエンジニアは、私が目指している誰かに価値を提供し、喜ばせるエンジニアにつながると考えています。

# なぜリーダーになりたいのか？

私は、人の役に立ち感謝されることにやりがいを感じるため、リーダーになりたいと考えています。

高校3年生の文化祭実行委員として備品管理のチーフを務めた際、文化祭が成功し周囲から感謝された経験から、自分の行動が人の役に立つことに大きなやりがいを感じました。

また、大学でのチーム開発でも、利用者にとって便利な機能を考えることにやりがいを感じてきました。

これらの経験から、チーム全体を動かしながらより大きな価値を提供できるリーダーとして、お客様に貢献したいと考えています。
