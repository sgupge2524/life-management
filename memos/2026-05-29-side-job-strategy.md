# 副業・学習方針メモ

## 背景

WebPro では Figma と STUDIO を学習している。
また、現在は卒業研究と Unity による 2D ゲーム開発にも取り組んでいる。

収入が少しでも入ると、自分自身の自信につながり、彼女にも安心してもらいやすくなる。
そのため、無理のない範囲でクラウドワークスなどの案件獲得にも挑戦する。

## 基本方針

当面は、収入を狙う軸と成長を狙う軸を分けて考える。

- 収入を狙う軸：Figma・STUDIO を使った Web 制作系案件
- 成長を狙う軸：Unity による 2D ゲーム開発

Unity は長期的な武器として育てる。
一方で、今すぐ案件に挑戦する場合は、WebPro で学んだ Figma・STUDIO を活かした小さな案件から始める。

## 狙う案件

### 優先して探す案件

- STUDIO を使った簡単なサイト制作
- STUDIO 既存サイトの修正
- Figma での LP デザイン
- Figma でのワイヤーフレーム作成
- バナーや簡単な UI デザイン
- 既存デザインの修正・調整

### 慎重に判断する案件

- WordPress の本格的なサイト制作
- JavaScript を多用する高度な実装
- EC サイト構築
- 大規模な LP 制作
- 納期が短すぎる案件
- 要件が曖昧すぎる案件

## 今の目標

いきなり大きく稼ぐことを目指すのではなく、まずは次の経験を得ることを目標にする。

- クラウドワークスでプロフィールを整える
- 小さな案件に応募する
- クライアントとやり取りする
- 納品まで経験する
- 最初の実績と評価を得る

金額の目標は、まず月 1 万円を目安にする。

## 優先順位

1. 卒業研究を最優先で進める
2. Unity の 2D ゲーム開発を継続する
3. Figma・STUDIO のポートフォリオを整える
4. Figma・STUDIO 案件を探して応募する

## 注意点

案件を取ることを急ぎすぎない。
受注してから対応できずに苦しくなると、学習にも卒業研究にも悪影響が出る。

最初は「稼ぐこと」よりも「小さく実績を作ること」を重視する。
