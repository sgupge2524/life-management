## Graduation Research

### テーマ

AIを活用した学習データ提供要請文作成支援

### 目的

学習データの利活用には、教育改善や学習支援につながる価値があります。
一方で、個人情報保護や合意形成の観点から、学習者や保護者に対して分かりやすく納得しやすい説明を行う必要があります。

本研究では、生成AIを活用して、学習データの提供要請文作成を支援する仕組みについて検討します。

### 主な作業

- [ ] 関連研究の整理
- [ ] 学習データの分類整理
- [ ] 情報提供要請文の構成要素の検討
- [ ] 生成AIを用いた要請文作成方法の検討
- [ ] 仮想実証実験の設計
- [ ] 実験結果の分析
- [ ] 卒業論文の作成
- [ ] 発表資料の作成

### Keywords

- Learning Analytics
- 教育DX
- 個人情報保護
- 合意形成
- Generative AI
- Prompt Engineering
- 仮想実証実験
