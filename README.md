# Life Management

このリポジトリは、日々のタスクや取り組みを GitHub Issues で管理するためのリポジトリです。

## 使い方

### Issue でタスクを管理する

やることは Issue として作成します。

- 1つの Issue には、1つの目的を書く
- 作業内容が大きい場合は、複数の Issue に分ける
- 完了したら Issue を close する

### Markdown で作業内容を整理する

Issue の本文には、必要に応じてチェックリストを使います。

```md
## 目的

この Issue で達成したいことを書く。

## 作業内容

- [ ] 作業1
- [ ] 作業2
- [ ] 作業3

## 完了条件

- 何ができたら完了とするかを書く。
```

### 状況が変わったら Issue を更新する

取り組む内容や優先順位は変わるため、README には細かい計画を書きすぎません。

現在のタスク、進捗、優先順位は Issue 側で管理します。

## 運用方針

- タスクを見える形にする
- 大きな作業は小さく分ける
- 完璧に整理するより、継続して使うことを優先する
- README は最低限の使い方だけを記述する
