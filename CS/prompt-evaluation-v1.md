# 学習データ提供要請文生成結果・評価 v1

## 目的

本ファイルでは、`prompt-design-v1.md` で作成したプロンプトを実行した結果を記録し、生成された要請文の良い点・課題点を整理する。

6月のCS研究室ゼミに向けて、単にプロンプトを作成するだけでなく、実際に生成結果を確認し、今後の改善点を明確にすることを目的とする。

---

## 1. 実行対象

- 使用プロンプト：`prompt-design-v1.md` のプロンプト初版
- 入力例：入力例1「学習支援システム改善」
- 出力対象：保護者向けの学習データ提供要請文

---

## 2. 入力例1：学習支援システム改善

```text
- 要請者：○○大学 情報システム部
- 対象者：小学生の保護者
- 取得する学習データ：学習時間、回答履歴、正答率、ログイン履歴
- 利用目的：学習状況を把握し、児童一人ひとりに合った学習支援を行うため
- 利用期間：2026年4月から2027年3月まで
- 保存期間：利用終了後3年間
- 第三者提供の有無：第三者提供は行わない
- 同意しない場合の影響：同意しなくても授業参加や成績評価に不利益はない
- 同意撤回の方法：問い合わせ先にメールで連絡することで撤回できる
- 問い合わせ先：○○大学 情報システム部 example@example.com
```

## 3. 生成結果1

```markdown
件名：学習データの利用に関するご協力のお願い

平素より本学の教育活動にご理解とご協力をいただき、誠にありがとうございます。

○○大学 情報システム部では、児童一人ひとりにより適した学習支援を行うことを目的として、学習に関するデータの利用を予定しております。つきましては、下記内容をご確認のうえ、ご理解とご協力をお願いいたします。

今回取得するデータは、学習時間、回答履歴、正答率、ログイン履歴です。これらの情報を活用することで、学習の進み具合や理解状況を把握し、児童それぞれの状況に応じた学習支援や教材改善に役立ててまいります。

データの利用期間は2026年4月から2027年3月までを予定しております。また、取得したデータは利用終了後3年間保存し、その後は適切な方法で削除いたします。

保護者の皆様に安心していただけるよう、個人情報および学習データの適切な管理に努めてまいります。ご不明な点がございましたら、お気軽にお問い合わせください。

問い合わせ先

メールアドレス：[example@example.com](mailto:example@example.com)
```

## 4. 生成結果1の評価

| 観点 | 評価 | コメント |
|---|---|---|
| 分かりやすさ | 良い | 専門用語が少なく、保護者向けに読みやすい文章になっている。 |
| 目的の明確さ | 良い | 学習状況の把握と個別支援という目的が説明されている。 |
| データ内容の明確さ | 良い | 取得するデータの種類が具体的に記載されている。 |
| 利用期間・保存期間 | 良い | 利用期間と保存期間が明記されている。 |
| 第三者提供 | 良い | 第三者提供を行わないことが明確に書かれている。 |
| 同意しない場合の影響 | 良い | 不利益がないことが明記されており、安心感がある。 |
| 同意撤回 | 良い | メールで撤回できることが説明されている。 |
| 問い合わせ先 | 普通 | 問い合わせ先はあるが、担当者名や電話番号は記載されていない。 |
| 文章量 | 普通 | 丁寧だが、やや長く感じる可能性がある。 |
| 具体性 | 普通 | データ管理方法や削除方法の具体的説明は不足している。 |

---

## 5. 良い点

- 保護者向けに丁寧で自然な文章になっている。
- 取得する学習データ、利用目的、利用期間、保存期間が明確である。
- 第三者提供を行わないことが分かりやすく説明されている。
- 同意しない場合の不利益がないことを明記しており、読み手の不安を軽減できている。
- 同意撤回の方法が示されている。

---

## 6. 課題点

- データの管理方法が「適切な管理」と表現されており、やや抽象的である。
- 保存期間終了後の削除方法が具体的ではない。
- 問い合わせ先に担当者名や電話番号がないため、連絡先としては最低限である。
- 文章全体が丁寧である一方で、やや長く、読む負担がある可能性がある。
- 「教材改善」という内容が入力例には明示されていないが、生成結果に含まれているため、AIが目的を少し拡張している。

---

## 7. 改善方針

次回のプロンプト改善では、以下の点を検討する。

1. 入力情報にない内容を追加しすぎないように指示する。
2. データ管理方法を入力項目に追加する。
3. 保存期間終了後の処理方法を入力項目に追加する。
4. 要請文の簡潔版と詳細版を分けて生成する。
5. 出力後に「入力情報に基づいている部分」と「AIが補足した部分」を区別できるようにする。

---

## 8. 現時点で分かったこと

最小入力項目だけでも、保護者向けの学習データ提供要請文を生成することは可能である。

一方で、生成AIは入力情報に含まれていない内容を自然に補足する場合がある。そのため、研究では単に文章を生成するだけでなく、入力情報に対する忠実性や、説明の十分性を評価する必要がある。
