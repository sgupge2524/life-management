# 卒業研究計画（仮）

## 研究テーマ

生成AIを用いた学習データ提供要請文作成支援システムの開発

---

## 研究背景

教育現場では学習データの利活用が進められているが、学習者や保護者に対してデータ利用の目的や利用方法を適切に説明することが求められる。

しかし、学習データ提供要請文の作成には専門知識が必要であり、説明内容の不足や表現のばらつきが発生する可能性がある。

そこで本研究では、生成AIを活用して学習データ提供要請文を作成する支援システムを開発し、要請文作成の効率化および品質向上を目指す。

---

## 研究目的

利用者が学習データの利用目的や利用条件を入力することで、生成AIが学習データ提供要請文を自動生成するシステムを開発する。

また、生成された要請文の品質や有用性を評価し、生成AIを活用した要請文作成支援の有効性を検証する。

---

## システム概要（仮）

### 入力

- 利用目的
- 利用期間
- 利用する学習データ
- 第三者提供の有無
- 個人情報保護に関する条件

### 出力

- 学習データ提供要請文

### 利用技術（予定）

- OpenAI API
- Python
- LangChain
- Webアプリケーション（未定）

---

## 評価方法（案）

### 評価観点

- 要請文の分かりやすさ
- 要請文の網羅性
- 要請文作成時間
- 利用者満足度

### 評価方法案

#### 案1

人手作成要請文と生成AI作成要請文を比較する。

#### 案2

複数の評価者に要請文を確認してもらいアンケートを実施する。

#### 案3

生成AI利用前後の作成時間を比較する。
